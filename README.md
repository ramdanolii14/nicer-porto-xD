# nicer-porto-xD

Personal portfolio website built with [Astro](https://astro.build), deployed on Vercel.

**Live:** [work.ramdanolii.my.id](https://work.ramdanolii.my.id)

---

## Stack

- **Framework:** Astro 4

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
nicer-porto-xD/
├── public/       # Static assets
├── src/          # Astro pages & components
├── astro.config.mjs
└── package.json
```
